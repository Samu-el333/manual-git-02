## Introduccion a Github

GitHub es una plataforma en la nube para alojar código y control de versiones usando Git. Permite guardar proyectos, registrar cambios y colaborar con otros desarrolladores en equipo de forma ordenada.Para dar tus primeros pasos y registrarte, puedes acceder directamente a la página oficial de GitHub.Conceptos ClavesRepositorio: Carpeta o espacio donde se guardan los archivos y el historial de un proyecto.Commit: Guardado o registro de los cambios hechos en el código.Branch (Rama): Copia del proyecto para trabajar en mejoras sin afectar la versión principal.Pull Request

 El Flujo de Trabajo Básico _(GitHub Flow)_ Cuando trabajas en un proyecto, normalmente sigues estos pasos:Crear una Rama  _(Branch)_: Creas un espacio seguro para hacer tus experimentos sin dañar el código que ya funciona (llamado rama main o master).Hacer Commits: Guardas tus avances con un mensaje corto que explica qué cambiaste (por ejemplo: "Se agregó el botón de inicio").Abrir un Pull Request  _(PR)_ : Avisas a tu equipo (o a ti mismo) que tus cambios están listos para ser revisados.Hacer  _Merge_ : Si todo está bien, fusionas tus cambios con el código principal.🔍 Herramientas Clave de ColaboraciónGitHub no es solo para guardar código, es una red social para desarrolladores:Issues (Problemas): Una sección para reportar errores, sugerir ideas o planificar tareas pendientes en el proyecto.Forks: Crear una copia exacta de un proyecto de otra persona en tu propia cuenta para que puedas modificarlo libremente.GitHub Pages: Una función gratuita para publicar páginas web estáticas (como tu portafolio) directamente desde tu repositorio.🛠️ Tus Primeros Comandos en la TerminalSi quieres conectar tu computadora con GitHub usando la terminal de comandos, estos son los cuatro comandos que usarás el 90% del tiempo:git init: Inicia un proyecto local de Git en tu carpeta.git add .: Prepara todos tus archivos modificados para ser guardados.git commit -m "mi mensaje": Guarda los cambios de forma local.git push: Sube tus cambios guardados directamente a GitHub en internet.
