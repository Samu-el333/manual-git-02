# Solución de problemas

## Problema

La aplicación no puede conectarse a la base de datos MySQL.

## Error encontrado

El programa muestra un error de conexión cuando se intenta iniciar.

## Posible causa

Las credenciales de acceso a MySQL no eran correctas.

## Solución

Se revisaron los datos de conexión y se corrigieron el usuario,
la contraseña y el nombre de la base de datos.

## Resultado

Después de realizar los cambios, la aplicación logró conectarse
correctamente a MySQL.
