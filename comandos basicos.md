# Comandos básicos

## ¿Qué son?

Los **comandos básicos** son instrucciones que se utilizan en la **terminal** para darle órdenes a una computadora. Permiten trabajar con archivos, carpetas y diferentes funciones del sistema de una manera rápida.

## Comandos principales

- `cd` → Permite **cambiar de carpeta o directorio**.
- `ls` / `dir` → Muestra los **archivos y carpetas** que se encuentran en el directorio actual.
- `mkdir` → Sirve para **crear una nueva carpeta**.
- `rm` / `del` → Permite **eliminar archivos**.
- `cp` / `copy` → Sirve para **copiar archivos o carpetas**.
- `mv` / `move` → Permite **mover o cambiar el nombre** de un archivo.
- `clear` / `cls` → **Limpia la pantalla** de la terminal.
- `exit` → Se utiliza para **cerrar la terminal**.
